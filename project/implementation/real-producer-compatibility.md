# Real Producer Compatibility Report — 2026-04-28

Tracks Broadset's compatibility with files emitted by real third-party producers for PPTX, PDF, PSD, and SVG. Companion to `release-quality-closure-plan.md` units RQ-4 through RQ-9.

This is the **working** report — pass/fail/waived rows update as fixtures land and validation runs. Final release signoff happens at the bottom of this document (RQ-9.1).

## Fixture Governance

### Fixture classes

Every producer fixture in this repo is exactly one of the four classes below. The class determines storage location, license-redistribution rules, and validation harness behavior.

| Class                            | Storage                                                                                                                 | License gate                                                                                                                    | When used                                                                                                                                             |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A. Committed redistributable** | `packages/formats/src/<format>/__fixtures__/` with a `MANIFEST.md` per file                                             | Producer license MUST permit redistribution in this repo (MIT-style, public-domain, CC-BY without strong attribution overhead). | Default smoke + regression coverage. Runs in every `npm run test`.                                                                                    |
| **B. Generated by script**       | `packages/formats/scripts/generate-<producer>-fixtures.*` writes to `__fixtures__/generated/` (gitignored) at test time | n/a — bytes are produced fresh from `pdf-lib`, `ag-psd`, `pdfkit`, `jspdf`, `python-pptx` etc.                                  | Adversarial / quirky shapes that would be tedious to author by hand. Runs in every `npm run test`.                                                    |
| **C. Private / licensed mount**  | `BROADSET_PRIVATE_FIXTURE_ROOT/<format>/<producer>/<file>` outside the repo. Path is set per-developer via env var.     | Producer license forbids redistribution OR file size exceeds the small-fixture budget.                                          | Real Photoshop / PowerPoint / Illustrator output. Runs only when the env var is set; `RELEASE_VALIDATION=1` makes it a hard fail when missing.        |
| **D. Manual-only**               | None — producer is a desktop app with no scripted interface.                                                            | n/a                                                                                                                             | PowerPoint-on-Windows visual sanity, Affinity Designer save/open, Inkscape SVG round-trip on Linux. Tracked here as a row with a documented protocol. |

### Manifest format

Every committed fixture (class A) carries a row in its directory's `MANIFEST.md`:

```md
| File | Format | Producer | Producer version | OS  | Export path | License | Expected import | Expected re-export | Known limitations |
| ---- | ------ | -------- | ---------------- | --- | ----------- | ------- | --------------- | ------------------ | ----------------- |
```

Required fields:

- `File` — relative path inside `__fixtures__/`.
- `Format` — `pptx` / `pdf` / `psd` / `svg`.
- `Producer` — exact tool name as it self-identifies (`Microsoft PowerPoint`, `Adobe Illustrator`, `Inkscape`, etc.).
- `Producer version` — exact version string. Mac/Windows producers may also list build.
- `OS` — `macOS 14`, `Windows 11`, `Linux`, etc.
- `Export path` — UI menu/keystroke that produced the file (`File → Save As → SVG`, `File → Export → PDF`).
- `License` — license under which the file is committed. MUST be one of: `public-domain`, `MIT`, `CC-BY-4.0`, `CC0-1.0`, `MPL-2.0` (compatible with this repo). If the producer's license does not allow redistribution, the fixture is **NOT** class A.
- `Expected import` — short prose: what Broadset SHOULD recover (element types, fonts, layout fidelity).
- `Expected re-export` — short prose: what Broadset SHOULD round-trip if asked to re-emit.
- `Known limitations` — known fidelity loss this fixture documents (`gradient stops collapse to first stop`, `embedded TrueType replaced with Type1`, etc.).

### Storage rules

- Class A fixtures MUST be ≤ 1 MB each. Real-world large producer files belong in class C.
- Class B scripts MUST be deterministic — same inputs produce byte-identical outputs across runs. This makes the fixture pseudo-committed without polluting git.
- Class C fixtures MUST never enter the repo via `git add` or PR. CI release-validation jobs mount them via a secret-managed volume; local runs read them via `BROADSET_PRIVATE_FIXTURE_ROOT`.
- Class D rows MUST cite the protocol document that describes how to run the manual check (e.g. `project/spec/formats/pptx.md` → `## Spec Gaps` → "PowerPoint-on-Windows manual sanity").
- Secrets, license material, watermarked PDFs, customer files MUST NEVER be committed regardless of class.
