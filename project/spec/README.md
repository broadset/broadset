# Spec — Behavioral Source of Truth

This folder contains the **behavioral specifications** for broadset.
These files define **what the system must do** and are the canonical product-level requirements.

## Entry points

- `executive-summary.md` — high-level product overview derived from the domain specs
- `model/spec.md`
- `playback/spec.md`
- `renderer/spec.md`
- `editor/spec.md`
- `formats/spec.md`
- `ui/spec.md`
- `demo/spec.md`

## Scope boundary

- Put **behavioral requirements** and acceptance criteria here.
- Put **implementation structure and technical definitions** in `../implementation/`.
- Put **repo-level workflow and meta guidance** in the root docs: `../../README.md` and `../../AGENTS.md`.
